Juxbly playground

A local server for exercising the whole tool lifecycle on pages you control.

Run

pnpm test:e2e

That builds the extension into .output/chrome-mv3, starts this server, loads the unpacked extension into Chromium, and walks one tool through the entire lifecycle. Every model call is answered by a local recording, so a run costs nothing and a red run means the product changed — not that the model was in a mood.

The browser driver is Playwright. It is deliberately not a dependency of this repository yet — every pnpm install would otherwise fetch a browser for people who only run the unit suite — so install it once per machine: 

pnpm add -D -w playwright && pnpm exec playwright install chromium

If it already lives somewhere else on your machine, point the harness at it instead: JUXBLY_PLAYWRIGHT_HOME=/path/to/a/directory/with/node_modules pnpm test:e2e.

Model

Requests to /v1/chat/completions are answered from a recorded set, keyed by which part of the product asked (apps/playground/lib/model-mock.mjs). The harness switches what it answers from: 

GET  /__harness/state
POST /__harness/reset
POST /__harness/page       { "variant": "shop" | "changed" }
POST /__harness/scenario   { "proposeMode": "direct" | "clarify-first",
                             "semanticVerdict": "ok" | "suspicious" }

Call counts are read server side — that is the only authoritative place to count them.
